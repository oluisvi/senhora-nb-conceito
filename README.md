# Senhora NB — vitrine conceitual

Prévia mobile-first da Moda Feminina Atemporal, com dez referências fotográficas do catálogo público, filtros, busca e seleção de peças para consultar pelo WhatsApp.

Abra `index.html` para visualizar localmente. A prancha de apresentação está em `arte/prancha.html`.

As imagens vieram do PDF ligado ao Linktree público da marca. Títulos são descrições visuais; disponibilidade, tamanhos e valores devem ser confirmados com a loja. Não há checkout nem inventário.
